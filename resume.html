核心项目 AKNOWLEDGE BASE & RETRIEVAL

镜我计划 · 本地知识库与语义检索系统

2026.09 – 至今（约 10 周）　·　独立设计与实现

一个人维护的技术知识库，以及它配套的检索系统。目标不是"记笔记"，是让每一次踩坑的结论只被推导一遍。

  • 规模　43 篇结构化知识笔记 / 60 万字节 / 850 个语义块，覆盖跨版本 API 迁移、故障归因、工具链建设四个领域
  • 检索　本地 BAAI/bge-small-zh-v1.5 embedding + SQLite 向量库，单次混合检索 422 ms，API 费用 0 元——刻意不接云端，因为"查自己的笔记"不值得按次付费
  • 方法层　单独抽出 3 篇只写方法、不写结论的排障方法论（黑盒行为归因、参考实现契约提取、契约八维度清单），使结论可复用而非单次经验
  • 工程约束　自建"已验证结论 / 未验证推测"分流规则：只有编译通过、实机跑通、有日志或哈希为证的条目才允许入库

核心项目 BAI MEDIA PIPELINE

AI 素材与视频生产管线

2026.09 – 至今（约 8 周）　·　独立设计与实现　·　无独立显卡

在一台只有 Intel 核显、15.7 GB 内存的机器上，把"生成素材 → 合成视频"做成了可复用的本地管线。

  • 产出　8 分 25 秒带自动配音与字幕的成片（源素材 15 分钟 4.28 GB），45 条字幕全自动生成；同期产出 286 张游戏内可用贴图，封装为 5 套资源包
  • 工程规模　76 个 Python 脚本 / 9,141 行，覆盖切片、转场、字幕烧录、程序化贴图、抠图、像素化、批量出图
  • 成本工程　模型量化后 CPU 推理，768px 出图 340–400 s/张，全链路 API 支出 0 元；离线中译英模型（312 MB）替代在线翻译，规避网络与计费依赖
  • 关键归因　出图质量问题的根因不是算力，是提示词——步数 8→20（669 s → 1,019 s）效果无差别，改词后 12 步（477 s）反而最好
